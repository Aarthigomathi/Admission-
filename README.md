# Admission-

The application lives in [`admission-portal/`](./admission-portal) — **CampusConnect**, a
real-time college admission portal built from scratch (React 19 + Vite frontend,
Express 5 + SQLite backend, JWT auth, socket.io realtime).

```bash
cd admission-portal/server && npm install && npm run seed && npm start
# → http://localhost:5000   (API + web app on one port)
```

See [admission-portal/README.md](./admission-portal/README.md) for the full guide,
demo college logins and verification commands.
