# Admission Platform — Frontend

This folder contains the React + Vite frontend. Frontend source, tests, assets,
package manifests, and Vite configuration live here; backend code is maintained
separately in `../backend`.

## Run locally

```bash
npm install
npm run dev
```

## Build and lint

```bash
npm run build
npm run lint
```

See the repository root [README](../README.md) for the platform overview and
backend setup instructions.
