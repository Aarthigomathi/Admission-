# Frontend

This folder contains the React/Vite client for the Tamil Nadu College Admission Portal. For the combined frontend/backend setup, Windows VS Code instructions, API proxy, environment variables, demo accounts, and database details, see the project-root [`README.md`](../README.md).

Quick start from this folder:

```powershell
Copy-Item .env.example .env
npm ci
npm run dev
```

The backend should also be running on port 8080 for API-backed login, registration, and persistence.
